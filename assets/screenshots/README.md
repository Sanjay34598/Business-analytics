# Application Assets & Screenshots

This directory contains visual assets, brand icons, and screenshots for the **Business Analytics Platform**.

## Screenshots Directory Structure

```
assets/
└── screenshots/
    ├── dashboard_overview.png   # Main BI Executive Dashboard
    ├── dataset_management.png   # Dataset switcher & CSV upload modal
    ├── forecast_analytics.png   # Time-series ML sales forecasting
    ├── reports_analytics.png    # Executive PDF/CSV reports view
    └── settings_overview.png    # System configuration & model parameters
```

## Guidelines for Screenshots

- **Aspect Ratio**: 16:9 widescreen display (1920×1080 resolution recommended).
- **Format**: PNG or WebP format for optimal crispness.
- **Theme**: Dark mode interface with dynamic gradient visualizations.
