# Application Screenshots

This directory serves as the asset repository for UI screenshots referenced in `README.md` and documentation.

## Standard Screenshot Guidelines

When adding screenshots to this directory, please adhere to the following specifications:

- **Format**: PNG or WebP
- **Resolution**: 1920×1080 (1080p full display) or 2560×1440 (2K crisp display)
- **Theme**: Dark / Sleek Modern Interface
- **Naming Convention**:
  - `dashboard_overview.png` - Main Executive Dashboard view displaying KPI cards, sales trends, and category distribution.
  - `dataset_management.png` - Dataset list view showing dataset switching, analysis status, and upload modal.
  - `forecast_analytics.png` - Sales forecasting page with confidence intervals and interactive timeline filtering.
  - `reports_analytics.png` - Reports page showing export options (PDF / CSV) and executive summaries.
  - `settings_overview.png` - System configuration and dataset settings page.
